* org-agenda-api

A JSON HTTP API for accessing and manipulating org-agenda data in GNU Emacs. Enables external applications to read and manage TODO items, scheduled items, and deadlines programmatically.

** Features

- REST-like JSON API for org-mode data
- Docker container with supervisord process management
- Git synchronization for org files
- Caching with automatic invalidation
- Custom capture templates
- Health monitoring

** Quick Start

*** Docker (Recommended)

Build and run the container:

#+begin_src bash
nix build .#container
docker load < result
docker run -p 8080:80 -v /path/to/org:/data/org org-agenda-api
#+end_src

With git sync:

#+begin_src bash
docker run -p 8080:80 \
  -e GIT_SYNC_REPOSITORY=git@github.com:user/org-files.git \
  -v /path/to/ssh_key:/secrets/ssh_key:ro \
  org-agenda-api
#+end_src

*** Development

#+begin_src bash
nix develop
pytest tests/           # Run tests
pytest tests/ -v        # Verbose output
#+end_src

** MCP Server

The =org-agenda-mcp= sidecar exposes four MCP tools over the existing HTTP API:
=org_agenda=, =org_capture=, =org_complete=, and =org_update=. It supports both
stdio and hosted Streamable HTTP and does not read or modify org files directly.

Configure and run it locally:

#+begin_src bash
export ORG_AGENDA_API_USER=imalison
export ORG_AGENDA_API_PASSWORD_COMMAND='pass show org-agenda-api-imalison'
# ORG_AGENDA_API_URL defaults to the production URL
nix run .#mcp-server
#+end_src

An MCP host should launch this exact command and pass the environment variables
above (or =ORG_AGENDA_API_PASSWORD=) in its server configuration:

#+begin_src text
nix run /home/imalison/projects/org-agenda-api#mcp-server
#+end_src

The container also runs the Streamable HTTP transport under supervisord and
proxies it through nginx at =/mcp=. It uses the same Basic Auth credentials as
the JSON API. For the production container, remote MCP hosts connect to:

#+begin_src text
https://org-agenda-api.rocket-sense.duckdns.org/mcp
#+end_src

To run the HTTP transport directly during development:

#+begin_src bash
nix run .#mcp-server -- --transport streamable-http --port 2026
#+end_src

The sidecar accepts these environment variables:

| Variable                              | Description |
|---------------------------------------+-------------|
| =ORG_AGENDA_API_URL=                  | HTTP API base URL (default: =https://org-agenda-api.rocket-sense.duckdns.org=) |
| =ORG_AGENDA_API_USER=                 | Required Basic Auth username |
| =ORG_AGENDA_API_PASSWORD=             | Basic Auth password; takes precedence over the command |
| =ORG_AGENDA_API_PASSWORD_COMMAND=     | Shell command whose first stdout line supplies the password |
| =ORG_AGENDA_MCP_HOST=                 | Streamable HTTP bind host (container default: =127.0.0.1=) |
| =ORG_AGENDA_MCP_PORT=                 | Streamable HTTP port (container default: =2026=) |

Scheduled and deadline tool arguments use =YYYY-MM-DD= or
=YYYY-MM-DDTHH:MM=. In =org_update=, an explicit =null= clears a field, while
an omitted field is left unchanged. There is deliberately no delete tool.
=org_capture= always selects =capture-g=, so the target API deployment must
register that template in =org-agenda-api-capture-templates=; the fallback
templates in the minimal container do not include it.

The Nix container includes =/bin/org-agenda-mcp=. Supervisord runs its HTTP
transport on the loopback interface alongside Emacs, nginx, git sync, and the
health checker; only nginx exposes it. The stdio transport remains available
for hosts that launch MCP servers as child processes.

** API Endpoints

*** Query Endpoints (GET)

| Endpoint             | Description                                |
|----------------------+--------------------------------------------|
| =/get-all-todos=     | Returns all TODO items from agenda files   |
| =/agenda=            | Returns agenda entries for a date range    |
| =/get-todays-agenda= | Returns today's scheduled and deadlined items |
| =/agenda-files=      | Lists configured org-agenda-files          |
| =/todo-states=       | Returns active and done TODO states        |
| =/custom-views=      | Lists available custom agenda commands     |
| =/custom-view?key=X= | Runs a specific custom agenda view         |
| =/templates=         | Lists registered capture templates         |

Common query params:
- =include_archives=true= for =/get-all-todos=, =/agenda=, and =/agenda-files= to include archive files/trees.

*** Create/Capture Endpoints (POST)

| Endpoint   | Description                      |
|------------+----------------------------------|
| =/capture= | Uses registered capture templates |

*** Modification Endpoints (POST)

| Endpoint   | Description                                          |
|------------+------------------------------------------------------|
| =/update=  | Updates TODO fields (scheduled, deadline, priority, effort, properties) |
| =/complete= | Marks TODO as complete                               |

*** Utility Endpoints (GET)

| Endpoint        | Description                            |
|-----------------+----------------------------------------|
| =/health=       | Health check for monitoring            |
| =/version=      | Returns git commit hash                |
| =/debug-config= | Returns org configuration for debugging |
| =/restart=      | Graceful restart for process managers  |

*** Habit Endpoints (requires org-window-habit)

These endpoints are available when =org-window-habit-mode= is enabled:

| Endpoint                                             | Description                                                        |
|------------------------------------------------------+--------------------------------------------------------------------|
| =/habit-config=                                      | Returns org-window-habit configuration (colors, display settings, behavior) |
| =/habit-status?id=<org-id>&preceding=N&following=N= | Returns detailed habit status with graph data                      |

Additionally, when org-window-habit is enabled:
- =/get-all-todos= entries include =isWindowHabit= and =habitSummary= fields
- =/agenda= entries include =isWindowHabit= and =habitSummary= fields
- =/complete= response includes =habitSummary= when completing a window-habit

** Environment Variables

| Variable               | Description                                   |
|------------------------+-----------------------------------------------|
| =GIT_SYNC_REPOSITORY=  | Git repo URL to clone on startup              |
| =GIT_SYNC_INTERVAL=    | Sync interval in seconds (default: 60)        |
| =GIT_SYNC_NEW_FILES=   | Include untracked files (default: true)       |
| =GIT_SSH_PRIVATE_KEY=  | SSH private key content                       |
| =GIT_USER_EMAIL=       | Git user email for commits                    |
| =GIT_USER_NAME=        | Git user name for commits                     |
| =ORG_AGENDA_FILES=     | Colon-separated list of org file paths        |
| =ORG_INBOX_FILE=       | Path for new captures (default: /data/org/inbox.org) |
| =ORG_API_MAX_REQUESTS= | Max requests before worker restart            |
| =ORG_API_MAX_LIFETIME= | Max seconds before worker restart             |

** Custom Emacs Configuration

To include your own Emacs config with additional packages:

#+begin_src bash
# Step 1: Bootstrap packages
nix run .#bootstrap-emacs-config /path/to/emacs.d

# Step 2: Build container with your config (in your flake.nix)
container = org-agenda-api.lib.${system}.mkContainer {
  emacsConfigDir = ./path/to/emacs.d;
  emacsConfigEntryPoint = "org-config.el";
};
#+end_src
